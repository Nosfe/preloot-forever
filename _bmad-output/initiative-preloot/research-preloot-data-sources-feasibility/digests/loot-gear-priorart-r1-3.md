## Leads
- Blizzard Classic profile API docs (https://community.developer.battle.net/documentation/world-of-warcraft-classic/profile-apis): the page is a JavaScript app and returned no content. Needs a rendered browser or the docs JSON to confirm the equipment endpoint and namespace for Anniversary (TBC) realms.
- Blizzard API Terms of Use: read the actual text of §2(b) and §2.2.18 / §2(r) (30-day retention; no premiums).
- TMB public loot tables (https://thatsmybis.com/loot) and wiki "Loot table pages": a possible TBC/Forever boss→item dataset; licensing and export are unknown.
- RCLootCouncil2 wiki (https://github.com/evil-morfar/RCLootCouncil2/wiki): import/export formats (CSV/TSV history export, TMB import?).
- Gargul wiki (https://github.com/papa-smurf/Gargul/wiki) and Gargul's LICENSE file text; the softres.it import format in Gargul's Softres class.
- AtlasLootClassic forks (102): check for an Anniversary-maintained fork with Phase 3–5 fixes.
- Wowhead "Black Temple Loot" and "Mount Hyjal Loot" guides for the current tier (manual cross-check only, given the ToS).

## Leads
- Inspect the raw HTML of /bis-list/fury-warrior/ with a plain HTTP GET, e.g. `Invoke-WebRequest … | Select-String "wowhead|item=|data-|__NEXT_DATA__|\.json"`. This would settle item IDs, server vs JS rendering, and whether there is a JSON data file. The fetch tool here can't show attributes or scripts.
- Look in the browser DevTools Network tab while switching the Phase dropdown. If phase changes fire an XHR, its data endpoint may hold the full phase list and item IDs.
- Check whether hovering an item loads Wowhead tooltips (the power.js/tooltips script). That would imply Wowhead IDs are hidden in the markup.
- Look for a Terms and Conditions page at /terms/ or /terms-and-conditions/, or email wowtbc.gg@gmail.com to ask permission to reuse the BiS data.
- If the only key is a name slug, map names to Wowhead TBC IDs with a separate item database (e.g. wowsims or Wowhead data dumps).
- Search GitHub for existing scrapers across all of GitHub. The search tool here needs an owner/repo scope, so the single query run here couldn't search site-wide.
